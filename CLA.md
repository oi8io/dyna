## How to sign

**Small contributions** — add a `Signed-off-by` trailer to each commit,
asserting agreement with this document:

```bash
git commit -s -m "your message"
```

**Substantial or organizational contributions** — email the Maintainer at
`hxangel@gmail.com` with the subject `CLA — <your GitHub handle>` and the
following, before your first pull request is merged:

```text
Full name:
GitHub username:
Email:
Employer (if the work is done on company time):
Country:

I have read the Dyna Studio Contributor License Agreement and I agree to it.

Signature:  ______________________    Date:  ____________
```

Signed CLAs are recorded in the project's private records. Contributors who have
not signed will be asked to do so before their pull request is merged.
